# # 🎓 Student Complaint Portal

A modern web-based **Student Complaint Portal** designed to simplify the process of submitting, tracking, and managing student complaints.

Students can register complaints and monitor their progress, while administrators can access a dedicated admin dashboard to manage complaints efficiently.

## 🌐 Live Demo
🔗 **[View Live Demo](LIVE_DEMO_LINK)**

## ✨ Features

### 👨‍🎓 Student Features
- User registration and login
- Submit complaints with category, priority, and description
- Track complaint status
- View submitted complaints
- Easy-to-use and responsive interface

### 👨‍💼 Admin Features
- Dedicated Admin Dashboard
- View all submitted complaints
- Search and filter complaints
- Update complaint status:
  - Open
  - In Progress
  - Resolved
- Change complaint priority:
  - Low
  - Medium
  - High
- One-click option to mark complaints as resolved
- View complaint statistics and status counts
- View student details associated with complaints

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- TanStack Router
- TanStack React Query
- Supabase
- Tailwind CSS
- Node.js
